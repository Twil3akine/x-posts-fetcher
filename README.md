# x-posts-fetcher

X（Twitter）公式 API v2 を使って、指定したアカウントの投稿を期間指定で取得し、JSON で出力する小さなツールです。Python 3 の標準ライブラリのみで動作し、外部依存はありません。

取得窓は既定で「前日 00:00〜24:00（設定したタイムゾーン）」なので、毎朝の定期実行で「昨日の投稿を全部拾う」といった用途に向いています。

もともとは、個人プロジェクトの朝刊システムで毎朝の発行に使う投稿取得の仕組みとして作ったものを、`.env` で対象アカウントを設定できる単体ツールとして切り出したものです。

## セットアップ

### 1. Bearer Token を取得する

1. [X Developer Portal](https://developer.x.com/) にログインし、Project と App を作成します。
2. 読み取りを行うには、App を **Pay Per Use（従量課金）** のプロジェクトに接続し、クレジットをチャージしておく必要があります（残高が空だと読み取りは失敗します）。
3. App の「Keys and tokens」にある **Bearer Token** を控えます。これが認証情報です。

課金は従量制です。投稿の読み取り単価は 2026 年 10 月時点で 1 件あたり約 $0.005、ユーザープロフィールの読み取りは約 $0.010 とされています（単価は変更されることがあります。最新の料金は Developer Portal で確認してください）。

### 2. .env を用意する

```bash
cp .env.example .env
```

`.env` を編集します。

```ini
X_BEARER_TOKEN=your_bearer_token_here
X_ACCOUNTS=account1,account2
TZ=Asia/Tokyo
```

| キー | 必須 | 説明 |
| --- | --- | --- |
| `X_BEARER_TOKEN` | ○ | App の Bearer Token |
| `X_ACCOUNTS` | ○ | 取得したいユーザー名（`@` なし、カンマ区切り） |
| `TZ` | 任意 | 取得窓の基準にするタイムゾーン（IANA 名）。既定は `Asia/Tokyo` |

`.env` は `.gitignore` に含まれています。トークンをコミットしたり公開したりしないでください。

## 使い方

前日分を取得して標準出力へ:

```bash
python3 fetch.py
```

ファイルへ出力:

```bash
python3 fetch.py --output posts.json
```

期間を明示する（ISO 8601。タイムゾーンなしの値は `TZ` の時刻として解釈されます）:

```bash
python3 fetch.py --from 2026-10-25T00:00:00 --to 2026-10-26T00:00:00
```

## 出力形式

```json
{
  "fetched_at": "2026-10-26T00:00:00Z",
  "window": {
    "start": "2026-10-24T15:00:00Z",
    "end": "2026-10-25T15:00:00Z"
  },
  "accounts": {
    "account1": [
      {
        "id": "2001",
        "created_at": "2026-10-25T01:23:45.000Z",
        "text": "hello https://t.co/abc",
        "urls": ["https://example.com/article"],
        "url": "https://x.com/account1/status/2001"
      }
    ]
  }
}
```

- `window` は実際に API へ送った取得期間（UTC）です。
- `urls` は投稿本文中のリンクを展開したもの（`entities.urls` の `expanded_url`）の一覧です。
- 取得は 1 回のリクエストで最大 100 件、ページング（`next_token`）をたどって全件を取得します。

## テスト

ネットワークを使わない自己テスト（ダミーの API レスポンスで窓計算とパースを検証）が付属しています。

```bash
python3 test_fetch.py
```

## 注意事項

- このツールは読み取り専用です。投稿・いいね・フォローなどは行いません。
- API のエラー（401: トークン不正、402: クレジット不足、429: レート制限など）時は、トークンを出力に含めず、状態を示すメッセージとともに非ゼロで終了します。
- 同一リソースの再取得は課金が重複しない場合がありますが、実行回数には注意してください（料金体系は変更されることがあります）。
- 取得した投稿データの取り扱いは、X の利用規約および開発者ポリシーに従ってください。
